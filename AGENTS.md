# legros.dev Agent Guide

## Summary

This is a personal website generated by Hugo (https://gohugo.io/).  The website is
for Brian LeGros, a software engineer who focuses on web development.

## Commands
- **Dev Server**: `hugo server -D` (Run in background for preview)
- **Build**: `hugo --minify` (Generates `public/` directory)
- **Test**: Run `hugo` to verify build succeeds. No unit tests configured.
- **Lint**: Use `prettier --check .` (HTML/CSS/MD). Use theme config if possible.

## Code Style & Conventions
- **Stack**: Hugo (Go Templates). Zero-JS preference.
- **Structure**:
  - `content/`: Markdown files (`kebab-case` filenames).
  - `layouts/`: Template overrides (Go HTML templates).
  - `static/`: Static assets (images, etc).
- **Formatting**: Format HTML/CSS/Markdown with Prettier.
- **Theme**: `themes/hugo-simple`. Check `themes/hugo-simple/AGENTS.md` for theme-specifics.
- **Config**: `hugo.toml` manages site settings.
- **Changes**: Prefer modifying `layouts/` or `content/` over editing theme directly.
- **Error Handling**: Hugo will fail build on template errors. Check console output.
